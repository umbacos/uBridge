# Third-party components

The TFT is compiled by the separately installed TJC USART HMI editor 1.68.2.
The vendor editor and vendor operating-system resources are not part of the
MIT-licensed application source. The editable native project is created in that
editor for this project. Font 0 is generated by that editor from Microsoft
Sans Serif at 20 pixels. Normal drawing is performed with TJC GUI commands.

The bundled 24px icon masks are rasterized from Material Design Icons webfont
**7.4.47**, copyright Pictogrammers and contributors, distributed under Apache-2.0.
They are modified binary masks for serial drawing, generated by `tools/build_icons.py`.
The upstream [font release](https://github.com/Templarian/MaterialDesign-Webfont/tree/v7.4.47)
and hashes are recorded in `custom_components/tjc_hmi/display/assets/provenance.json`.
The upstream notice and Apache-2.0 text are in that directory and in the portable
application's `licenses/MDI/` directory. Pillow is only used to rebuild these masks;
it is not required by the bridge or HA integration at runtime.

Python runtime dependencies are installed from PyPI by Home Assistant:
pyserial-asyncio-fast 0.16 and its pyserial dependency. Development tools and
the preview have separate optional dependencies listed in the README. Their
upstream licenses apply. The installation/source ZIPs do not bundle their Python
packages; the portable desktop application does.

uBridge uses Qt/PySide6 Essentials and Shiboken 6.12.0, copyright The Qt Company
Ltd. and contributors, under LGPL-3.0 (the upstream distribution also offers GPL
alternatives). The portable directory keeps Qt's shared libraries separately in
`_internal` so they can be replaced with compatible modified versions. Modification
of those libraries and reverse engineering to debug such modifications are permitted.
Copies of the LGPL and GPL are in `licenses/Qt/`; upstream notices are retained.
The corresponding upstream sources are available from
[Qt base v6.12.0](https://github.com/qt/qtbase/tree/v6.12.0) and
[PySide/Shiboken v6.12.0](https://github.com/qtproject/pyside-pyside-setup/tree/v6.12.0).
The application sources and build instructions are included in the source release.

The portable application also includes CPython, aiohttp and its dependencies,
keyring and its dependencies, pyserial, pyserial-asyncio-fast, the PyInstaller
bootloader, and applicable Microsoft VC runtime libraries from the Qt distribution.
Their upstream notices are copied to the portable `licenses/` directory where
provided by the installed distributions. CPython's license is additionally present
with its bundled runtime. The PyInstaller bootloader uses its distribution exception.

The desktop bundle includes tzdata (IANA time-zone database) for ZoneInfo on Windows
and other hosts without system zone data. Its Apache-2.0 package license and public
domain time-zone data notices are retained under the portable `licenses/tzdata/`.

The Windows MSI uses WiX Toolset/UI 5.0.2, copyright .NET Foundation and
contributors, under the Microsoft Reciprocal License (MS-RL). The license is
included as `licenses/WiX-MS-RL.txt`. The unmodified upstream sources are available
at [the exact WiX build commit](https://github.com/wixtoolset/wix/tree/aa65968c419420d32e3e1b647aea0082f5ca5b78).
The workspace downloads the compiler as a build tool; it is not installed alongside
the application. Generated installer authoring is produced by `tools/build_msi.py`.
